# Assets

Antes de fazer build com EAS, adiciona aqui:

- `icon.png` — 1024×1024, sem transparência (ícone da app)
- `adaptive-icon.png` — 1024×1024 (Android)
- `splash.png` — imagem do ecrã de arranque

Depois referencia-os em `app.json` (`expo.icon`, `expo.splash.image`,
`expo.android.adaptiveIcon.foregroundImage`).
